Privacy policy

What this study app stores on your device, what it never stores, and what it never sends.

MSc Cybersecurity Practise Syllabus 1st Year. Last updated 22 August 2026.

1. What this app is

This is a student study tool (quiz, terminal tutorial, class notes). The public copy is static files on GitHub Pages. It is not an official OsloMet service and it has no cloud account.

The person who publishes the files can update the quiz text. They cannot see your name, password, points or cards unless you show them your phone or send a score code yourself.

2. What we do not collect

  • No email address is required.
  • No cookies for tracking, ads or analytics.
  • No Google Analytics, Facebook pixels, or similar.
  • No third-party score cloud (nothing is posted to jsonblob or other hosts).
  • Passwords and reset words are never stored in plain text.
  • Quiz answers you type are not uploaded.
  • The app does not send your progress to another phone by itself.

3. What stays on this device

The browser stores data in localStorage and sessionStorage on this phone or PC only.

Account (this browser)

  • Display name you choose (max 24 characters).
  • Password check: salt + PBKDF2-SHA-256 (310000 iterations). The password itself is not saved.
  • Reset word: stored the same way (hashed), so you can recover the name or password on this device.
  • Share flag (off unless you tick it) and a random ranking id if you share.
  • Failed-sign-in lockout (count and wait time) so guessing is slowed down.

Study progress (encrypted when you are signed in)

  • Points, streak, trophies, due cards, drill lists.
  • Spaced-repetition queues and flash-card position.

Those values are wrapped with AES-GCM (ENC1.). After you sign out, or close the tab, the key leaves sessionStorage. Other people on this browser see ciphertext, not your scores.

Tutorial progress (this device, not in the vault)

  • Where you are in the ACIT4050 terminal tutorial.
  • Where you are in the Computer basics tutorial.
  • Last course tab you opened.

Those three items are ordinary browser storage. They are not your password and not a ranking score.

4. Sign-in session

While you are signed in, the tab keeps a short-lived session (including the vault key) in sessionStorage. Close the tab or press Sign out and the session is gone. Another classmate should not use the same tab while you are signed in.

5. Sharing is off unless you tick it

Default: nobody sees your points. If you tick Share my score on the class ranking, this browser can show your name, points, streak and trophy count to other accounts on the same device that also ticked Share.

You can also copy a score code that starts with MSC1|. That code holds only those four public fields plus a time stamp. Paste it only if you want that person to add you to their board. Password, reset word and quiz cards are never in the code.

Untick Share to leave the board on this device.

6. Offline cache

On HTTPS the service worker may cache the app files (HTML, quiz decks, icons) so the syllabus works offline. That cache is the course content, not your private scores. It does not use tracking cookies.

7. Honest limits

  • This is one browser, not a cloud login. A new phone starts empty unless you copy a score code (scores only) or use the same browser profile.
  • Anyone with this unlocked phone can open the site. Use a password and sign out.
  • While you are signed in, browser developer tools can see the session key. After sign-out the vault stays locked.
  • GitHub Pages can see that someone loaded the public files (normal web logs: IP, time, which file). That is GitHub, not a score database we run.

8. How to delete your data

  • Sign out, then clear site data for this page in the browser (or delete the site under Settings / Storage).
  • That removes accounts, encrypted scores, tutorial progress and the ranking board on this device.
  • If you already sent an MSC1| code to a classmate, ask them to ignore or remove that entry. We cannot delete it from their phone.

9. Course content vs your data

Quiz cards, notes and tutorials are study material. They are not your personal file. Your personal file is the name you type and the scores on this device.
